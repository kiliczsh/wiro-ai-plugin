# Audio workflows
Distinguish transcription, speech synthesis, translation, audio enhancement and music generation. Discover actual available models, inspect `get_model_schema`, verify language, voice, input URL, format and size restrictions. Do not assume voice cloning is available or permitted. Avoid submitting sensitive audio without user authorization. Execute once, poll existing task, deliver provider transcript or output link and confirm actual cost if returned. Clearly mark any transcription uncertainty.
